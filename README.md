# Performance Assessment Methods for Automated Vehicles — Supporting Data

This repository contains the supporting materials for the systematic literature
review *"Performance Assessment Methods for Automated Vehicles"*

The review synthesizes how automated-vehicle (AV) performance is assessed across
four research questions — assessment methodologies (RQ1), performance metrics
(RQ2), evaluation settings (RQ3), and standards engagement (RQ4) — based on 183
primary studies published between 2015 and 2025 and identified through a
PRISMA-guided screening process.

## Contents

| File | Description |
|------|-------------|
| `study_coding_data.xlsx` | Study-level coding for all 183 primary studies |
| `codebook.xlsx` | Definitions of every variable and coding value |
